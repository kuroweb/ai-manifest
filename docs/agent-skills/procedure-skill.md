# 手順型スキルの型

操作を順に実行して結果を返すスキルの`SKILL.md`の型。

## SKILL.mdの見出し構成

````markdown
---
name: [スキル名]
description: >
  [すること]
  [特徴]
  [呼び出し例]
  [使う場面]
  [使わない場面]
---

# [スキル名]

## できること

## いつ使うか

## 手順

## 禁止事項

## スキル連携

## コマンドリファレンス

## [追加の見出し]
````

- `できること`・`いつ使うか`・`手順`は必須。それ以外は書くことがあるときだけ書く
- 型の見出しの順序は変えない。`[追加の見出し]`は、読み手がその内容を必要とする位置に置く

## 見出しごとの書き方

### frontmatter

スキルの名前と、エージェントがスキルを選ぶための説明を書く。

```markdown
---
name: [スキル名]
description: >
  [すること]
  [特徴]
  [呼び出し例]
  [使う場面]
  [使わない場面]
---
```

- `[スキル名]` は、ディレクトリ名と同じにする
- `[すること]` は必須。このスキルがすることを一文で書く
- `[特徴]` は任意。確認することや制約など、似たスキルと見分ける点を書く
- `[呼び出し例]` は任意。引数の組み合わせごとに書く
- `[使う場面]` は必須。依頼の言い回し、名前での呼び出し、他のスキルからの読み込み、CIからの呼び出しなど、このスキルが使われる場面を書く
- `[使わない場面]` は任意。取り違えやすい場面と、代わりに使うスキルを書く
- 要素はテンプレートの順に書く。言い回しは決めない

### できること

このスキルでできることを書く。

```markdown
## できること

- [できること]
```

- `[できること]` は、利用者から見てこのスキルでできること。一項目に一つ書く
- 手順の一段、内部の確認や検証、他のスキルに任せる処理、コマンド、保存先の細部は書かない

### いつ使うか

このスキルを呼ぶ形と、使う場面を書く。

```markdown
## いつ使うか

- `[呼び出し例]`
- `[依頼]`
- [使う場面]
- [取り違えやすい場面]は使わない
```

- `[呼び出し例]` は、引数の組み合わせごとに一項目書く
- `[依頼]` は、このスキルを使う依頼の言い回し
- `[使う場面]` は、呼び出し例や依頼の言い回しに表れない場面
- `[取り違えやすい場面]` は、隣接するスキルを使うべき場面。そのスキル名を添えてよい

### 手順

実行する順に、Stepごとに書く。

````markdown
## 手順

### Step [番号]: [すること]

[判断や操作]

```bash
[コマンド]
```

[止まる条件]
````

- `[番号]` は、1から順に振る
- `[すること]` は、動詞で終わる一句
- `[判断や操作]` は、一つの判断か操作だけ書く
  - 値の決め方に優先順があれば、番号付きリストで書く
  - 書き方の型を持つときは、型を `references/schema.md` に置き、「`references/schema.md` を読み、その型で書く」と書く
  - 他のスキルに任せるときは、「`[スキル名]`で書く」のように委ねる先だけ書く
  - 最後のStepには、結果の検証と返すものを書く
- `[コマンド]` は、そのStepで実行するコマンド。無ければコードブロックごと省く
- `[止まる条件]` は、停止する条件、ユーザーに聞く条件、そのStepでしないこと。無ければ省く

### 禁止事項

どの手順でも破ってはいけないことを書く。

```markdown
## 禁止事項

- [禁止]
```

- `[禁止]` は、「〜しないこと」で書く

### スキル連携

このスキルが関わる依頼や状況と、そこで使うスキルを書く。

```markdown
## スキル連携

| ユーザーの依頼 | ワークフロー |
| --- | --- |
| [依頼] | `[スキル名]` → `[スキル名]` |
```

- `[依頼]` は、使うスキルが決まる依頼や状況
- `[スキル名]` は、そこで使うスキル。複数使うときは実行順に `→` でつなぐ

### コマンドリファレンス

手順で実行するコマンドと、その用途を書く。

```markdown
## コマンドリファレンス

| コマンド | 用途 |
| --- | --- |
| `[コマンド]` | [用途] |
```

- `[コマンド]` は、手順に出てくるコマンドだけ
- `[用途]` は、そのコマンドで何を確かめるか、何をするか

### [追加の見出し]

型の見出しに収まらない内容があるときに使う。

```markdown
## [追加の見出し]
```

- `[追加の見出し]` は、見出しだけで何の節か分かる名前にする
- 型の見出しに書ける内容は、型の見出しに書く
