# インラインコメントの型

## 文書構成

`code-reviewing` の指摘1件を、次の形で出す。

```markdown
**リスクレベル**: [リスクレベル]

#### [指摘見出し]

[本文]
```

### リスクレベル

見出しの上に置く。

```markdown
**リスクレベル**: [リスクレベル]
```

- `[リスクレベル]` は、その指摘の上にある見出しから、次の組み合わせで書く

  | 指摘の上にある見出し | `[リスクレベル]` |
  | --- | --- |
  | `Critical` | `🔴CRITICAL` |
  | `High` | `🟠HIGH` |
  | `Medium` | `🟡MEDIUM` |
  | `Low` | `🟢LOW` |

### 指摘見出し

```markdown
#### [指摘見出し]
```

- その指摘の見出しをそのまま書く
- 書き換えない

### 本文

見出しのあとに、その指摘の残りを入れる。

```markdown
[その指摘の本文]
```

- 見出し、文言、順序、コードブロックのインデントは変えない
