# インラインコメントの型

## 文書構成

`code-reviewing` の指摘1件を、次の形で出す。

```markdown
#### [リスクレベル] [指摘見出し]

[本文]
```

### 指摘見出し

```markdown
#### [リスクレベル] [指摘見出し]
```

- `[リスクレベル]` は、その指摘の上にある `Critical`、`High`、`Medium`、`Low` をそのまま書く
- `[指摘見出し]` は、その指摘の見出しをそのまま書く
- 書き換えない

### 本文

見出しのあとに、その指摘の残りを入れる。

```markdown
[その指摘の本文]
```

- 見出し、文言、順序、コードブロックのインデントは変えない
