# レポートの型

## 文書構成

次の順で出す。省略、並べ替え、追加をしない。空なら `なし`。`## 調査サマリー` だけは `なし` にしない。

```markdown
# [タイトル]

## 調査目的

## 調査サマリー

## 調査詳細
```

### タイトル

調査目的を端的に表す。

```markdown
# [タイトル]
```

- `[タイトル]` は、何を調べるか

### 調査目的

この調査で明らかにする問いを書く。

```markdown
## 調査目的

[調査目的]
```

- `[調査目的]` は、ユーザーが明らかにしてほしい問い。依頼の文言で書く
- 3 行ぐらいにする

### 調査サマリー

調査目的への答えを書く。概要がつかめればよい。

```markdown
## 調査サマリー

[結論]

[要点]
```

- `[結論]` は、問いへの答え
- 1 文、120 字ぐらいにする
- `[要点]` は、その答えを支える判断。無くてよい
- 最大 4 つ、各 1 文ぐらいにする

### 調査詳細

サマリーの答えを、一次情報のどこで確かめたかを書く。

```markdown
## 調査詳細

### [トピック見出し]

[根拠]
```

- `[トピック見出し]` は、その節で確かめる判断
- `[根拠]` は、その判断を確かめた一次情報の位置と、判断に必要な事実
- サマリーを裏付けるのに必要な分量にする
