# プランの型

会話断片しかなく、そのままでは再利用しにくいときだけ、この型で最小限に整形する。内容が無い見出しは残さない。

```markdown
# 概要

# 背景

# スコープ

# 実施ステップ

# 懸念点・リスク

# 未確定事項

# 次のアクション
```

## 概要

- プラン全体を 3〜6 個の箇条書きで要約する

## 背景

- なぜこのプランが必要か
- 何を解決するための計画か

## スコープ

- 対象
- 対象外

## 実施ステップ

- 実行順に並べる
- 可能なら各ステップの完了条件を一行で添える

## 懸念点・リスク

- 想定される失敗要因
- 判断待ち事項

## 未確定事項

- ユーザー確認が必要な点
- まだ結論を出していない点

## 次のアクション

- 直近でやることを優先順で書く
