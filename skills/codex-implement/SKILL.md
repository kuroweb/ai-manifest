# Codex Implement

Codex CLIをサブエージェントとして実行し、コード変更を完了させるスキル。相談・レビューのみの場合は `codex` スキルを使う。

## 実行コマンド

```bash
codex exec --full-auto --model gpt-5.4 --sandbox workspace-write --cd <project_directory> "<request>"
```

- `--sandbox workspace-write` がワークスペース内のファイル編集を許可する（read-only の `codex` スキルとの差分）
- 実装タスクは長時間かかるため、実行時のタイムアウトは10分程度に設定する

## プロンプトの組み立て

codexはこちらの会話コンテキストを一切持たない。`<request>` に以下を含める：

1. **依頼内容と背景**: 対象ファイルパス・関数名・再現手順など、こちらで判明している情報はすべて渡す（codexに再調査させない）
2. **制約**: 既存の振る舞いを変えない、対象外のファイルに触れない、など
3. **固定指示（末尾に必ず追加）**:

   > 確認や質問は不要です。提案に留めず、対象ファイルを実際に編集して変更を完了させてください。最後に変更したファイルと変更内容の要約を出力してください。

## 実行手順

1. 実行前に `git status` で作業ツリーの状態を記録する（codexの変更と既存の変更を区別するため）
2. 上記コマンドでcodexを実行する
3. 実行後に `git diff` で変更内容を検証し、依頼と一致しているか確認する。依頼外の変更が混ざっていれば指摘する
4. codexの要約と `git diff` の確認結果をユーザーに報告する
