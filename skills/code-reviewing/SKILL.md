# code-reviewing

## できること

- 渡されたdiffと変更目的を一次情報としてレビューする
- `references/checklist.md` に沿ってdiffを確認する
- 再確認と信頼度で問題を絞り、リスクレベルを付けて報告する
- `references/schema.md` の型でレビューをチャットへ返す

## いつ使うか

- 他のスキルが`code-reviewing`を読むよう指示したとき
- diffと変更目的が、呼び出し元または会話から渡されたとき

## 手順

### Step 1: diffと変更目的をそろえる

diffは必須である。呼び出し元または会話に無いときは、レビューを生成しない。

変更目的は次の順で決める。

1. 呼び出し元が渡した変更目的
2. 会話で示された変更目的
3. ユーザーに聞く

無ければ、一度に一つ聞く。PR本文の貼り付けでもよい。diffから変更目的を推測しない。

変更目的とdiffが矛盾した場合は、自動解決せず確認する。

### Step 2: 前提を読む

必要に応じて`AGENTS.md`、周辺コード、既存テストを読む。対象リポジトリのローカル規約は、一般的な慣習より優先する。

### Step 3: 問題を洗い出す

- diffと変更目的を照合し、意図しない変更や不足を確認する
- `references/checklist.md` を読み、上から順に確認する

### Step 4: 再確認する

洗い出した問題を、1件ずつ次の2点で確かめる。

1. 問題の箇所を読み直し、そのコードが問題の主張どおりかを確かめる。主張どおりでなければ除く
2. 問題を起こす具体的な入力や状態を挙げる。挙げられなければ、信頼度を低にする

### Step 5: 信頼度で絞る

コードから示せない問題は推測であり、レビューの信頼を下げる。各問題に信頼度を付け、扱いに従う。報告するのは中以上だけ。

| 信頼度 | 意味 | 扱い |
| --- | --- | --- |
| 高 | 示したコードから問題を証明できる。入力と誤った結果を挙げられる | 報告する |
| 中 | 問題の見込みは高いが、見えていない前提に依存する | 要確認と添えて報告する |
| 低 | コードの根拠が無い推測 | 報告しない |

### Step 6: リスクレベルとレビューカテゴリを付ける

残った問題に、次のリスクレベルを1つ付ける。

| リスクレベル | 基準 |
| --- | --- |
| `Critical` | 悪用できるセキュリティホール、データの損失・破壊、よく通る経路でのクラッシュ。マージ前に必ず直す |
| `High` | 現実的な入力で誤動作する不具合、深刻な性能劣化（N+1、際限ない増加）、既知の悪用が無い認証・入力検証の欠落。マージ前に直す |
| `Medium` | エッジケースの不具合、エラー処理の欠落、重要な振る舞いのテスト不足、近いうちに問題になる保守性の問題。直すか、別途対応する |
| `Low` | スタイル、命名、軽微な読みやすさなど、振る舞いに影響しないもの。任意 |

あわせて、次のレビューカテゴリを1つ付ける。

| レビューカテゴリ | 対象 |
| --- | --- |
| `セキュリティ` | シークレットの露出、インジェクション、認証・認可の欠陥、安全でない設定 |
| `破壊的変更` | APIの契約、DBスキーマ、既存の利用者や呼び出し元への影響 |
| `正確性` | ロジックの誤り、エッジケース、エラー処理、変更目的との食い違い |
| `性能` | アルゴリズムの非効率、DBクエリ、メモリやリソースの管理 |
| `品質` | コードの臭い、設計原則の違反、命名とドキュメント |
| `一貫性` | プロジェクトのパターン、命名規約、API設計、変更に対するテスト |

### Step 7: レビューを返す

`references/schema.md` を読み、残った問題をその型で組んでチャットへ返す。

## 安全条件

- diffなしでレビューを生成しない
- `references/checklist.md` を読まずに問題を洗い出さない
- Step 4 の再確認を通していない問題を報告しない
- `references/schema.md` を読まずにレビューを組まない
- 読んで確かめていない事実を断定しない
- 変更目的をdiffから推測しない

## スキル連携

| 状況 | 使用するスキル |
| --- | --- |
| 渡されたdiffをレビューする | `code-reviewing` |
| ローカルブランチのdiffをgitで取る | `code-review` |
| AIによるGitコマンド実行が禁止されている | `code-review-no-git` |
| 指定したGitHub PRをレビューする | `gh-pr-review` |
| CIから指定したGitHub PRをレビューする | `gh-pr-review-ci` |
| 指定したGitLab MRをレビューする | `glab-mr-review` |
