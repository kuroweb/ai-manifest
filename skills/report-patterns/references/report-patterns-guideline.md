# report-patterns の書き方

このファイルは report-patterns 自体の直し方。

## 記述パターンの形

`## 記述パターン` の直下には何も書かない。`###` から始める。

各 `###` は次の順。

1. 冒頭。そのパターンをいつ使うかだけ。スロットの埋め方、分からないときの扱い、リンク先の話は置かない
2. テンプレート
3. スロットと規則

## 書いてはいけないこと

- `## 記述パターン` 直下に、複数パターンに効く汎用ルールをまとめて置く
- 業務コードや特定プロダクトの例。うまい一般例が出せないならテンプレートにする

## 足すとき

- パターンは `###` を足す
- コード一件のリンク（テキスト、blob、URL が分からないとき）は `### コードリンク` に書く。リストパターンへコピーしない
- ラベリングをいつ書くかは冒頭。`[ラベリング]` に何を置くかはテンプレートの下
- テンプレートに位置を出すスロットは `[ラベリング]` `[補足]` のようにコードブロックへ明示する
