# 引き継ぎノートの型

## 文書構成

次の順で出す。省略、並べ替え、追加をしない。該当なしのセクションは `なし` と書く。

```markdown
# [タイトル]

## 今回やったこと

## 決定事項

## 捨てた選択肢と理由

## ハマりどころ

## 学び

## 次にやること

## 関連ファイル
```

### タイトル

今回のセッションで扱った作業を端的に表す。

### 今回やったこと

作業内容と進捗を箇条書きで書く。

### 決定事項

確定した設計判断、方針、ルールなどを書く。

### 捨てた選択肢と理由

検討したが採用しなかったアプローチとその理由を書く。次のセッションで同じ議論を繰り返さないための節なので、特に省かない。

### ハマりどころ

詰まったポイント、エラー、想定外の挙動などを書く。

### 学び

今回得られた知見、気づきを書く。

### 次にやること

未完了のタスク、次のセッションで着手すべきことを書く。優先度がわかるように書く。

### 関連ファイル

今回触った主要ファイルのパス一覧を書く。

## 書き方

- 簡潔に書く
- 箇条書き中心にする
- 推測や曖昧な表現は避け、事実ベースで書く
